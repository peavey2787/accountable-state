# Interoperability vectors

All formats are V1. Vectors are generated by `cargo run -p edge-p2p -- vectors tests/interoperability`
and checked by independent code:

| File | Rust check | Independent check |
|---|---|---|
| `merkle_sha256_v1.json` | gv-merkle tests | `scripts/verify-vectors.mjs` (Node SHA-256) |
| `signed_mldsa65_v1.json` | `crates/sig/tests/committed_vector.rs` | `scripts/verify-vectors.mjs` (SHA-512 envelope, SHA-256 player id, OpenSSL ML-DSA-65 verify) |
| `packed_controls_v1.json` | codec tests | `scripts/verify-event-codec.mjs` |

ML-DSA signing is hedged (randomized), so signatures are not reproducible from the seed; the committed
signature is verified, never regenerated. The OpenSSL checks need OpenSSL >= 3.5 and are skipped otherwise.
